# DNA Fabric Days

Build a small sales solution in Microsoft Fabric and take a change from your first notebook through Git review, Test deployment and an approved release to simulated Prod.

## Start here

- [Get ready for DNA Fabric Days](docs/tutorial/pre-reads/README.md) covers access, tools and optional background reading.
- [Participant tutorial](docs/tutorial/README.md) is your guide for the workshop. Start with Unit 0 to check your team's assigned workspaces and repositories.
- [Tiny Sales starter](sample/tiny-sales/README.md) contains the notebook cells and report measures used in the exercises.
- [Fabric deployment starter](deployment_starter/README.md) explains the shared YAML and Python you use in the optional Unit 12 lab.

This repository contains the workshop instructions and starter files. Build Tiny Sales in your team's assigned Azure DevOps repositories and Fabric workspaces. You can work on your own or follow the same sequence with a partner.
