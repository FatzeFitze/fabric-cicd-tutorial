## Use in the new project

> Read docs/context-handoff/README.md and its linked context files, then README.md, AGENTS.md and docs/planning/decisions.md in this repository. Use the supplied Working Version 1 guidelines as the baseline. Reconcile later explicit decisions before changing plans. Start with a gap review of the existing Section 3 implementation and a proposal for the smallest workshop feasibility experiment. Do not assume historical lab success validates the new cross-workspace setup.
